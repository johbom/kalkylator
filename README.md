# Kalkylator

Kalkylator med stora, tydliga knappar, gjord för att kunna köras i bland annat Grid3.

**Öppna den:** https://johbom.github.io/kalkylator/

## Funktioner
- `+ − × ÷`, parenteser, roten ur (`√`) och upphöjt till (`xʸ`)
- Historik över tidigare uträkningar
- Inställningar där man väljer vilka räknesätt som ska synas
- Kopiera / Klistra in, Ångra, Rensa och Sudda
- Ljust och mörkt läge

## Filer
Hela kalkylatorn är en enda fil, `index.html`, utan externa beroenden. Den fungerar även offline om man öppnar filen lokalt.
